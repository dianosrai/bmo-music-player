# bmo-music-player
A cute mini music player that looks like BMO from the cartoon Adventure Time.

## 🎵 How to Download & Run

### Method 1: Download the Desktop Installer (Recommended)
1. Go to the **Releases** section on the GitHub repository page.
2. Download the latest `BMO Setup.exe` file.
3. Double-click the installer to install the music player on your Windows PC. It will automatically create a desktop shortcut for you!

*Note: As a developer, you can generate this installer by running `npm run dist`, which creates the setup file in the `dist/` directory. You can then upload it to your GitHub Release.*

---

### Method 2: Run from Source (For Developers)
If you want to run the project from source, make sure you have [Node.js](https://nodejs.org/) installed:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/dianosrai/bmo-music-player.git
   cd bmo-music-player
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Run the application:
   ```bash
   npm start
   ```
